# Clubhouse Player Door

The player-facing door for Anthony's Clubhouse Poker Room league — hosted on GitHub Pages so any player can open it in a real browser, save it to their home screen, sign up once, and check in on game night.

**Live:** https://aruikis.github.io/clubhouse-player-door/

What lives here:

- `index.html` — the Door itself (a single self-contained page; its data layer talks to the league book exactly as the Muse-space copy does)
- `manifest.webmanifest`, `sw.js` — the pieces that make the page a genuinely installable web app (home-screen icon, standalone launch). The service worker caches only this page's own shell files and never caches league data.
- `icon-*.png`, `apple-touch-icon.png` — the Clubhouse medallion icons, generated by `generate_icons.py` (Midnight Brass: near-black field, brass ring, club motif)

Players' phone numbers and emails are never shown on this page — name and stats only. Contact details stay host-only in the league book.
